lightbulb

Web Analytics 是什麼？

Web Analytics 是 Cloudflare 免費、隱私優先的網站分析，讓你看到人們怎麼使用你的網站，包括瀏覽量、造訪數、熱門頁面、訪客從哪裡來，以及頁面開起來有多快。它完全不用 Cookie、也不蒐集個人資料，從設計上就尊重訪客隱私。

groups

把它想成店門口的人流計數器

店門口的人流計數器會告訴你進來幾個人、哪些走道最熱鬧，卻不問任何人的名字。Web Analytics 也是這樣計算造訪數與熱門頁面：給你有用的數字，但不做個人追蹤。

不管你的網站有沒有經過 Cloudflare 代理，它都能運作。對於不在 Cloudflare 後面的網站，你只要加上一小段叫做「信標（beacon）」的 JavaScript 就好。

help

為什麼選它，而不是一般的分析工具？

很多分析工具依賴 Cookie 並蒐集個人資料，這會拖慢網站、觸發 Cookie 同意橫幅，也帶來隱私疑慮。Web Analytics 採取更輕量、更尊重隱私的做法。

cookie

不用 Cookie

訪客裝置上不存任何東西，所以你常常不需要單為分析掛上 Cookie 同意橫幅。

shield_person

隱私優先

它不對使用者做指紋辨識、也不蒐集個人資料，讓 GDPR 等法規的遵循容易許多。

feather

輕量

信標非常小，並用 defer 延後載入，幾乎不影響你網頁的載入速度。

monitoring

真實效能資料

它回報來自真實造訪的核心網頁指標（Core Web Vitals），讓你看到真實使用者體驗到的速度。

瀏覽量與造訪數

瀏覽量（page views）計算共載入了幾個頁面；造訪數（visits）計算從你網站開始的瀏覽工作階段。

trending_up

熱門頁面與來源

看到哪些頁面最受歡迎，以及哪些網站或搜尋把訪客帶來給你。

public

國家、瀏覽器、裝置

依地點、瀏覽器，以及是用手機還是電腦來了解你的受眾，全部都是匿名的。

speed

核心網頁指標

來自真實造訪的 LCP、INP、CLS，告訴你頁面是否載入快、反應快、版面穩。

rocket_launch

怎麼把它加到你的網站

  1. 開啟 Web Analytics

    在 Cloudflare 儀表板進入 Analytics & Logs > Web Analytics，然後選「Add a site（新增網站）」。

  2. 輸入你的主機名稱

    輸入你網站的主機名稱（例如 example.com）並確認。Cloudflare 會為它產生一個專屬的追蹤權杖（token）。

  3. 複製信標程式碼

    在「Manage site（管理網站）」複製 JS 程式碼。裡面有一個 data-cf-beacon 屬性，存著你的專屬 token，用來告訴 Cloudflare 這些資料屬於哪個網站。

  4. 貼在 body 結束標籤之前

    把程式碼加到你 HTML 頁面的 </body> 之前。幾分鐘內，資料就會開始出現在儀表板上。

html信標程式碼
<!-- Cloudflare Web Analytics -->
<script defer
  src="https://static.cloudflareinsights.com/beacon.min.js"
  data-cf-beacon='{"token": "YOUR_UNIQUE_TOKEN_HERE"}'></script>
<!-- End Cloudflare Web Analytics -->

tips_and_updates

小提示與計費

block

留意廣告攔截器

部分廣告或隱私攔截器會擋掉外部分析腳本，所以你真實的數字可能比報表稍高一點。但長期的趨勢仍能告訴你什麼有效。

  • Web Analytics 在所有 Cloudflare 方案都免費。
  • 用篩選器（Filters）聚焦在某個路徑、國家或來源。
  • 把信標加到每一頁（或共用的版型）上，才不會漏掉流量。
  • 它不需要改 DNS，也不需要 Cloudflare 代理，網站放在哪裡都能用。
