lightbulbSmart Shield 是什麼？

Smart Shield 是 Cloudflare 對「網站一經過代理就自動生效的防護」的統稱。它會智慧管理流量、優化內容傳遞，並保護你的來源基礎設施（origin infrastructure），把效能與安全綁在一起，讓初學者不必逐一手動設定，就能擁有合理又安全的預設值。

info

它是組合，不是單一開關

Smart Shield 最好理解成 Cloudflare 一組自動的邊緣行為，包括免費 SSL、預設快取、DDoS 緩解、智慧路由與壓縮。實際包含哪些功能會依方案而定；本頁以誠實、通用的方式描述這些防護。

security

把它想成大樓的智慧門廳

任何人在抵達你的辦公室（來源伺服器）之前，都要先經過有人員駐守的門廳。它會查證件、擋掉鬧事者、從附近的架上直接把訪客要的東西給他，並引導他走最快的走廊，這一切都自動完成。

help它為你做了什麼？

分別設定效能與安全既困難又容易出錯。Smart Shield 提供經過實戰考驗的預設值，讓常見的防護直接就是開著的。

https

處處免費 HTTPS

免費的 SSL/TLS 憑證自動加密訪客與 Cloudflare 之間的流量，不用買憑證，你的網站就有那個安全鎖頭。

gpp_good

DDoS 防護

Cloudflare 龐大的網路會在阻斷服務攻擊（DDoS）抵達並壓垮你的伺服器前，先把它吸收並過濾掉。

visibility_off

隱藏來源伺服器

代理會藏起你伺服器真實的 IP 位址，攻擊者看到的是 Cloudflare，而不是你的主機。

smart_toy

機器人緩解

自動檢查會把真實訪客和惡意機器人、爬蟲分開，減少垃圾流量。

route

智慧流量管理

流量會被導向有效率的路徑，能用快取就用快取，減輕來源伺服器的負擔。

compress

自動壓縮

邊緣會套用 Brotli 等現代壓縮與 HTTP/3 等通訊協定，縮小並加快回應。

rocket_launch怎麼開啟它

大多數 Smart Shield 防護只要讓網域的流量經過 Cloudflare 就會啟用。關鍵步驟是把你的 DNS 紀錄設為代理。

  1. 代理你的 DNS 紀錄

    在 DNS > Records，確認 A／AAAA／CNAME 紀錄顯示橘色雲朵。這個開關會把流量導入 Cloudflare，並啟用邊緣防護。

  2. 把 SSL/TLS 設成安全模式

    在 SSL/TLS 裡選 Full (strict)（完整嚴格），讓訪客、Cloudflare 與來源伺服器之間全程加密。

  3. 啟用 Always Use HTTPS

    開啟「Always Use HTTPS（一律使用 HTTPS）」，讓任何 http:// 請求自動升級成安全的 https:// 版本。

  4. 確認防護已生效

    檢查回應標頭，看到「server: cloudflare」就代表流量已經穿過邊緣並受到保護。

    bash
    curl -sI https://example.com | grep -iE 'server|cf-ray'
# server: cloudflare
# cf-ray: 8a1b2c3d4e5f6789-LAX

tips_and_updates小提示與計費

tune

先用預設值，再來微調

自動預設值對幾乎所有人都安全。等你上手後，再疊上 WAF 規則、更細的快取規則與 Argo 智慧路由，走得更遠。

  • 核心防護如免費 SSL、預設快取與不限量 DDoS 緩解，在免費方案就有。
  • 進階部分（如 Argo 智慧路由或更高階 WAF）是付費升級。
  • 務必選 Full (strict) SSL，連到來源伺服器的連線才會一起加密。
  • 別代理郵件相關紀錄，MX 與郵件驗證紀錄保持僅 DNS（灰色雲朵）。
