Cloudflare 是什麼？

Cloudflare 是全世界最大的電腦網路之一，分布在超過 330 個城市。大家最熟悉的是它能讓網站更快、更安全，但它同時也是一個「開發者平台」（developer platform，給工程師寫程式、跑程式的地方）——你可以在這個遍布全球的網路上寫程式並執行，完全不用自己租或管理伺服器（server，也就是負責處理請求、提供服務的電腦）。

這個概念叫做「在 Cloudflare 上打造（build on Cloudflare）」：你不用買一台放在某個地點的電腦，而是讓你的程式碼在全球各地、離使用者最近的地方同時執行。你只要負責寫程式碼，Cloudflare 幫你準備好運算的電腦、儲存空間、資料庫，甚至是 AI。

lightbulb

把它想成…

傳統的伺服器就像在某個城市開「一家」餐廳，所有客人都得大老遠跑來找你。Cloudflare 則像一台會瞬間出現在 330 多個城市的餐車，餐點永遠在點餐的人旁邊就做好端上。你只要交出食譜（也就是你的程式碼），餐車早就遍布各地了。

第一步：開一個免費帳號

底下所有步驟都需要一個 Cloudflare 帳號。好消息是：它免費、大約一分鐘就好，而且一開始不需要信用卡。

  1. 打開註冊頁面

    在瀏覽器打開 dash.cloudflare.com/sign-up。這就是 Cloudflare 的「控制台」（Dashboard，用滑鼠點一點就能管理所有東西的網頁後台）。

  2. 輸入電子郵件與密碼

    填入電子郵件和一組夠強的密碼後送出。請用一個你打得開的真實信箱。

  3. 驗證你的信箱

    Cloudflare 會寄一封含「驗證連結」的信給你，點一下確認這個帳號是你的。

  4. 完成，進入控制台

    現在你會看到控制台畫面。要跟著本課程做，你「不需要」先加入網站或網域（domain，像 example.com 這種網址）——免費的 Workers 方案本身就能用。

lock

開啟兩步驟驗證

在帳號設定裡開啟「兩步驟驗證」（two-factor，登入時要再輸入一組臨時代碼）。花一分鐘養成這個習慣，就能讓你的專案更安全。

terminal

第二步：安裝 Wrangler CLI

Wrangler 是 Cloudflare 的「命令列工具」（CLI，Command-Line Interface，一種用打字輸入指令來操作的程式）——你在「終端機」（terminal，輸入文字指令的黑色視窗）裡打指令，就能建置與部署你的程式碼。控制台用來點一點，Wrangler 則用來把成品送上線。

check_circle

先準備好 Node.js

Wrangler 需要 Node.js（一個能在你電腦上執行 JavaScript 的工具）。請先到 nodejs.org 安裝 Node.js 18 或更新的版本。安裝後在終端機輸入 node -v 確認有裝好。

  1. 安裝 Wrangler

    在終端機輸入下面這行。-g 代表「全域安裝」，這樣你在任何資料夾都能使用 wrangler 指令。

    bash
    npm install -g wrangler

  2. 登入 Cloudflare

    這會打開瀏覽器，問你是否允許 Wrangler 使用你的帳號。點「Allow（允許）」後回到終端機，它就認得你了。

    bash
    wrangler login

  3. 確認登入成功

    這會印出目前登入帳號的電子郵件。看到你的信箱，就代表可以進到下一步了。

    bash
    wrangler whoami

第三步：部署你的第一個 Worker

「Worker」是一段小小的程式碼，跑在 Cloudflare 的網路上，負責回應網頁請求。我們現在就來建立一個，並把它真正放上網路。

  1. 建立專案

    這個指令（叫做 C3）會在一個名為 my-first-worker 的新資料夾裡，幫你建好一個可以馬上執行的專案範本。它會問你幾個問題，請看下一步。

    bash
    npm create cloudflare@latest -- my-first-worker

  2. 回答設定問題

    當它問你要從什麼開始，選「Hello World example（範例）」；範本選「Worker only（只要 Worker）」；語言選「JavaScript」。問你要不要現在部署時先選「否」，我們等一下自己來部署。

  3. 看看產生出來的程式碼

    打開新資料夾，在 src/index.js 裡會看到下面這段 Worker。每次有人造訪，fetch 這個函式就會執行，並回傳一個 Response（回應，也就是訪客看到的內容）。

  4. 部署到全世界

    在專案資料夾裡執行這行。Wrangler 會把你的 Worker 上傳，並給你一個公開網址，像是 my-first-worker.<你的名稱>.workers.dev。用瀏覽器打開它——那就是你的程式碼正在線上運作了。

    bash
    npx wrangler deploy

接下來學什麼？

光是一個 Worker 就很強大，但真正的應用程式還需要「記住資料」「存放檔案」，有時還要會「思考」。下面是你接下來可以學的方向——每一個在本站都有專屬課程。

key

記住小東西 — KV

Workers KV 是簡單的「鍵值資料庫」（key-value，用一個名稱對應一份資料），就像一面巨大的便利貼牆，存設定、計數器、開關都很合適。

folder

存放檔案 — R2

R2 用來存放大型檔案，像圖片、影片、備份——而且把檔案下載出去不收「流量費」。

table

用資料庫 — D1

D1 是內建在平台裡的真正 SQL 資料庫，適合存有結構的資料，例如使用者、訂單。

smart_toy

加上 AI — Workers AI

Workers AI 讓你在 Worker 裡用一行呼叫，就能跑現成的 AI 模型（聊天、生圖、翻譯等）。

shield

保持安全 — 資安

認識 WAF（網站防火牆）、Turnstile（友善的真人驗證）與 Access（存取控管），擋掉惡意流量、隨著成長保護你的應用程式。

menu_book

閱讀官方文件

Cloudflare 官方文件對每個產品都有可直接複製貼上的範例。把它加到書籤，你會常回來查。

新手小提示

favorite

從小做起，先用免費

幾乎所有東西都能在免費額度內學會。先做小專案、放心去試錯，等到真的有專案、有大量流量時，再考慮付費就好。

  • 先用免費額度——每天 10 萬次請求，學習和個人小專案綽綽有餘。
  • 控制台 vs CLI：用控制台點一點來探索功能，但想要可重複、可寫成腳本的部署時就用 Wrangler。
  • 部署前先用 npx wrangler dev 在本機測試你的 Worker——又快又不花錢。
  • 卡關時先讀官方文件；幾乎每一頁都有可直接複製貼上、能跑的範例。
  • 盡早把專案用 Git 版本控制起來，這樣隨時都能還原改動。
  • 每個 Worker 都有免費的 .workers.dev 網址——不用買網域就能分享你的成果。
