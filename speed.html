Cloudflare Speed 是什麼？

Speed 是 Cloudflare 用來量測你網站到底有多快、並開啟各種優化讓它更快的中心。它包含 Observatory（用真實與合成資料做效能測試）、在 Cloudflare 私有網路上的智慧路由，以及一整套針對圖片、JavaScript、CSS 的內容優化。

directions_car

把它想成導航加上一次保養

Argo 智慧路由就像會看即時路況的導航，總是挑 Cloudflare 骨幹網路上最不塞的路。內容優化則像幫車子做保養，把圖片與程式碼縮小，讓你的網頁負重更輕、更快抵達。

許多速度功能在儀表板上只要一鍵，有幾項在網站經過 Cloudflare 代理後就自動啟用。

school

認識核心網頁指標（Core Web Vitals）

核心網頁指標（Core Web Vitals）是 Google 用來評估真實使用者體驗的三個量測值。Cloudflare 會回報這些數字，讓你清楚知道該改進什麼。

hourglass_top

LCP — 載入速度

LCP（Largest Contentful Paint，最大內容繪製）：畫面上最大的元素（通常是主視覺圖或大標題）出現要多久。目標是 2.5 秒以內。

touch_app

INP — 互動回應

INP（Interaction to Next Paint，互動到下次繪製）：使用者點擊或輕觸後，頁面多快有反應。目標是 200 毫秒以內。

crop_free

CLS — 視覺穩定度

CLS（Cumulative Layout Shift，累積版面位移）：頁面載入時內容跳動的程度。越低越好，目標是 0.1 以下。

help

有哪些優化可以用？

alt_route

Argo 智慧路由

即時偵測壅塞，把流量導向 Cloudflare 私有骨幹網路上最快的路徑，平均比公開網路快約 30%。

layers

分層快取

增加一層上層快取，讓更少請求回到來源伺服器，提高快取命中率。

compress

圖片優化

Polish 會壓縮圖片，並能轉成 WebP 等現代格式；圖片縮放（resizing）則為每種裝置送出剛好的尺寸。

data_object

JS 與 CSS 優化

壓縮並精簡 JavaScript 與 CSS（minify），讓瀏覽器下載與執行更少的程式碼。

bolt

Early Hints 與 Speed Brain

Early Hints 讓瀏覽器更早開始抓重要資源；Speed Brain 則預先載入訪客可能會點的下一頁。

lan

現代通訊協定

邊緣支援 HTTP/3、0-RTT 與 Brotli 壓縮，縮短連線交握時間與傳輸大小。

怎麼開始用

  1. 用 Observatory 跑一次測試

    在儀表板進入 Speed > Observatory 跑一次測試。你會拿到效能分數、核心網頁指標，以及一份建議改進清單。

  2. 套用建議

    每條建議都連到一個可切換的設定，例如開啟 Brotli、Early Hints 或圖片 Polish，通常只要一個開關。

  3. 啟用 Argo 智慧路由

    進入 Traffic > Argo Smart Routing 並開啟。它是付費附加功能，但能立刻把你所有被代理的流量導向最快路徑。

  4. 用 Web Analytics 量測真實使用者

    加入 Cloudflare Web Analytics，就能持續觀察真實訪客的核心網頁指標，確認你的改動真的有效。

bash確認 HTTP/3 與 Brotli 已啟用
# Verify Brotli compression is being served
curl -sI -H 'Accept-Encoding: br' https://example.com | grep -i content-encoding
# content-encoding: br

# Verify HTTP/3 is advertised
curl -sI https://example.com | grep -i alt-svc
# alt-svc: h3=":443"; ma=86400
tips_and_updates

小提示與計費

insights

改動前後都要量測

改設定前先記下一次 Observatory 分數，改完再跑一次。真實的數字才會告訴你哪個開關真的讓你的網頁變快。

  • 許多優化（Brotli、HTTP/3、Early Hints、壓縮）在免費方案就能用。
  • Argo 智慧路由與部分圖片功能是依用量計費的付費附加功能。
  • 先修最糟的核心網頁指標，通常是 LCP，主要受主視覺圖與快取影響。
  • 把 Speed 和 CDN 一起用：快取加上智慧路由，效果最顯著。
