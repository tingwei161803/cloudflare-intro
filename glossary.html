詞彙表

被術語搞糊塗了嗎？搜尋任何 Cloudflare 或網路名詞，就能看到一句話、初學者也懂的解釋。

50 個術語

內容傳遞網路 (CDN)網路expand_more
一個遍布全球的伺服器網路，會在離使用者近的地方存放網站檔案的副本，讓網頁載入更快。CDN 是「內容傳遞網路」的縮寫。
分散式阻斷服務攻擊 (DDoS)安全expand_more
一種用海量假流量灌爆網站、讓它癱瘓並下線的攻擊。就像一群人把店門口擠爆，讓真正的顧客進不去。
反向代理 (Reverse proxy)網路expand_more
一台擺在你網站前面的伺服器，先接住訪客，再把請求轉給你的源站。這讓 Cloudflare 能在流量抵達你之前，先加上快取、安全防護與加速。
加密超文本傳輸協定 (HTTPS)網路expand_more
在 HTTP 上加了 TLS 加密的版本，讓你與網站之間的資料保持私密、不被竄改。字尾的 s 代表 secure（安全），瀏覽器會用鎖頭圖示來表示。
任播 (Anycast)網路expand_more
一種網路技巧，讓全球許多伺服器共用同一個位址，你的請求會自動被導向最近的那一台。Cloudflare 就是用它在你毫無察覺下把你帶到附近的伺服器。
存活時間 (TTL)網路expand_more
一份快取副本或 DNS 紀錄在必須更新之前，可以被保留多久。TTL 是「存活時間」的縮寫；TTL 越短，代表資料更新得越頻繁。
佇列 (Queue)運算expand_more
給任務排隊用的等候線：你的應用把工作丟進去，系統就在背景一個一個處理，這樣在尖峰忙碌時也不會漏掉任何一件。就像熟食店的抽號碼牌，把點單按順序處理好。
冷啟動 (Cold start)運算expand_more
程式碼在處理第一個請求前，需要先「醒來」並準備就緒所造成的短暫延遲。Cloudflare Workers 設計成幾乎零冷啟動，所以幾乎不用等。
別名紀錄 (CNAME)網路expand_more
一種 DNS 紀錄，用來把一個網域名稱指向另一個，就像郵件的轉寄地址。例如 www.example.com 可以設成指向 example.com 的 CNAME。
快取 (Cache)網路expand_more
把資料的暫存副本放在靠近使用者的地方，這樣就能立刻提供、不必再大老遠重新取一次。就像把零食放在辦公桌抽屜，而不是每次都走去商店買。
延遲 (Latency)網路expand_more
資料從一端傳到另一端再回來所花的時間，通常以毫秒計算。延遲越低，感覺越靈敏；這也是為什麼「離使用者近」這麼重要。
物件儲存 (Object storage)儲存expand_more
一種把檔案當作獨立「物件」（檔案本身加上它的資訊）來存放的方式，可以擴充到非常龐大的資料量。很適合放照片、影片與備份；R2 就是 Cloudflare 的物件儲存。
流量限制 (Rate limiting)安全expand_more
一條規則，限制某個來源在一段時間內可以送出多少請求，藉此保護網站不被濫用或灌爆。就像「每位顧客限拿一份試吃」的規定。
區域 / Region: Earth網路expand_more
傳統雲端會要你替應用挑一個「區域」（某個資料中心的地點）。Cloudflare 提出的「Region: Earth」概念則是讓你的程式碼自動到處都跑，你不必選。
推論 (Inference)人工智慧expand_more
實際使用一個訓練好的 AI 模型來得到結果的動作，例如生成文字或辨識圖片。訓練是在「教」模型，推論則是「請」它做事。
通道 / cloudflared (Tunnel)安全expand_more
一條安全、加密的連線，讓 Cloudflare 能連到某台伺服器或應用，而不必把它直接暴露在公開網際網路上。負責建立這條通道的小程式叫做 cloudflared。
嵌入向量 (Embedding)人工智慧expand_more
一串能捕捉文字、圖片或聲音「語意」的數字，讓電腦可以比較兩個東西有多相似。意思相近的詞，算出來的數字也會相近。
無伺服器 (Serverless)核心概念expand_more
一種不必自己租用或管理伺服器就能執行程式碼的方式；平台會自動幫你跑，而且只有真的執行時才收費。其實還是有用到伺服器，只是你不用去管它。
超文本傳輸協定 (HTTP)網路expand_more
瀏覽器與伺服器用來請求和傳送網頁的基本規則。HTTP 是「超文本傳輸協定」的縮寫，可說是網路的共通語言。
傳輸層安全協定 (TLS / SSL)安全expand_more
一種把瀏覽器與網站之間的連線加密的技術，讓別人無法偷看或竄改資料。SSL 是較舊的名稱，TLS 是現代版本，兩者都會讓瀏覽器顯示那把鎖頭圖示。
源站伺服器 (Origin server)網路expand_more
網站真正內容所在的原始伺服器，Cloudflare 會先快取它並提供副本給使用者。Cloudflare 會保護源站，只有在必要時才去打擾它。
綁定 (Bindings)運算expand_more
你宣告的一種連結，讓 Worker 只要在程式碼中用一個名稱，就能使用資料庫、儲存桶或 AI 模型等其他資源。它把你的程式碼接到所需的服務上。
資料流出費 (Egress fee)儲存expand_more
某些雲端供應商在你把資料下載或搬出其儲存空間時加收的費用。Cloudflare R2 以零資料流出費聞名，所以把檔案拿出來不用付錢。
零信任 (Zero Trust)安全expand_more
一種資安做法，不會因為某人已在內部網路就假設他是安全的；每個使用者與每次請求都必須每次都證明自己。其精神就是「永不信任，每次驗證」。
圖形處理器 (GPU)人工智慧expand_more
一種能同時進行大量運算的特殊晶片，因此特別適合用來執行 AI 模型。Cloudflare 會在邊緣用 GPU 幫你跑 AI，你就不必自己購買。
網站應用防火牆 (WAF)安全expand_more
一種會檢查進入的網路流量、在惡意請求（例如駭客攻擊）抵達你網站前就擋下的過濾器。WAF 是「網站應用防火牆」的縮寫，可以想成門口的保全。
網域名稱系統 (DNS)網路expand_more
網際網路的電話簿，會把像 example.com 這種人類好記的名稱，轉換成電腦連線時用的數字位址。DNS 是「網域名稱系統」的縮寫。
憑證 (Certificate)安全expand_more
一張數位身分證，用來證明某網站確實是它所宣稱的身分，並啟用加密的鎖頭連線。它由受信任的機構簽發，就像政府核發護照一樣。
機器人 (Bot)安全expand_more
一種會自動造訪網站、而非真人的程式，有時有益（例如搜尋引擎），有時有害（例如爬資料的或攻擊者）。Cloudflare 能幫忙分辨好的與壞的機器人。
頻寬 (Bandwidth)網路expand_more
在一段時間內，一條連線能傳輸多少資料，就像水管的粗細。頻寬越大，代表一次能流過越多資料。
應用程式介面 (API)核心概念expand_more
兩個程式之間溝通與交換資料的一套既定方式，就像服務生幫你把點單送進廚房、再把餐點端回來。API 是「應用程式介面」的縮寫。
檢索增強生成 (RAG)人工智慧expand_more
一種讓 AI 先從你自己的文件裡查出相關資訊、再據此回答的技巧，能讓答案更準確也更即時。RAG 是「檢索增強生成」的縮寫。
鍵值 (Key-value)儲存expand_more
一種把資料存成「對」的簡單方式：一個獨一無二的「鍵」（標籤）配上它的「值」（內容），就像字典裡的詞與它的解釋。只要知道鍵，就能很快查到。
邊緣 (Edge)核心概念expand_more
分散在全球、實體上離使用者很近的伺服器；資料傳輸距離短，所以回應感覺很快。就像每個街角都有一家便利商店，而不是只有一間在遠方的大倉庫。
驗證碼 (CAPTCHA)安全expand_more
那種「證明你是人類」的小測驗，例如挑出有紅綠燈的圖片，用來分辨真人與機器人。它們有時很惱人，所以才會出現像 Turnstile 這類想取代它的工具。
Access (存取控管)安全expand_more
一項 Cloudflare 服務，在你的內部應用前面加上一道登入檢查，只有經核准的人才能進入，不需要 VPN。就像在私人應用門口擺一份賓客名單。
AI Gateway (AI 閘道)人工智慧expand_more
一個位於你的應用與 AI 模型之間的控制點，可加上快取、流量限制、紀錄與成本追蹤。就像一位聰明的櫃台人員，管理並記錄每一筆送往 AI 的請求。
Cloudflare Pages (網站託管)運算expand_more
一項用來託管網站與前端應用的服務，會直接從你的程式碼倉庫建置並部署。把你的 Git 專案接上去，Cloudflare 就會把網站上線到全球。
D1 (SQL 資料庫)儲存expand_more
Cloudflare 以 SQLite 為基礎打造的無伺服器 SQL 資料庫，用表格（含列與欄）存放結構化資料。當你需要真正的查詢時很好用，就像一張可以對它提問的整齊試算表。
DNS 解析器 (DNS resolver)網路expand_more
你的裝置用來向 DNS 電話簿查詢網站位址的服務。Cloudflare 提供的免費解析器 1.1.1.1 以快速又重視隱私聞名。
Durable Object (持久物件)運算expand_more
一種會記住自己資料的特殊 Worker，並保證同一個名稱只存在唯一一份，所以很適合協調聊天室、即時計數器這類東西。可以把它想成一位固定負責同一個櫃台、值得信賴的櫃員。
Gateway (安全閘道)安全expand_more
Cloudflare 的安全網路閘道，會過濾組織的網路流量，攔截惡意程式與不該造訪的網站。可以把它想成你的團隊上網時的一道安全檢查哨。
IP 位址 (IP address)網路expand_more
用來在網際網路上識別某台裝置或伺服器的數字位址，就像資料的郵遞地址。DNS 的存在，就是為了把名稱轉成這些數字。
R2 (物件儲存)儲存expand_more
Cloudflare 用來存放圖片、影片、備份等大型檔案的儲存服務，而且把資料下載出去不收流出費。就像一個超大的線上硬碟，把檔案拿回來時不會跟你收錢。
Turnstile (人機驗證)安全expand_more
Cloudflare 推出、用來取代拼圖式 CAPTCHA 的友善方案，會在背後悄悄確認訪客是不是真人，通常不必讓你點任何東西。沒那麼惱人，又一樣能擋掉機器人。
Vectorize (向量資料庫)人工智慧expand_more
一種儲存「嵌入向量」（用一串數字代表語意）的資料庫，能快速找出語意相近的項目。它讓搜尋可以依「意思」來找，而不是只比對一模一樣的字。
Worker (邊緣函式)運算expand_more
一小段在 Cloudflare 邊緣伺服器上、靠近使用者執行的程式碼，能在幾毫秒內處理每個網路請求。可以把它想成一個小幫手，在最近的門口迎接每位訪客。
Workers KV (鍵值儲存)儲存expand_more
一種簡單的儲存服務，用鍵值對（一個名稱配一個值）存放資料，並複製到全球各地讓任何地方都能快速讀取。很適合存設定、小型資料，以及讀取遠多於修改的內容。
Wrangler (命令列工具)工具expand_more
Cloudflare 用來在你電腦上建置、測試與部署 Workers 的命令列工具。它是開發者把程式碼送上邊緣時最常用的遙控器。
wrangler.toml (設定檔)工具expand_more
一個 Worker 專案的設定檔，你在裡面填寫專案名稱、進入點與綁定。它就像專案的設定表，Wrangler 在部署時會讀取它。
