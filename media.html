媒體 Media

上傳、最佳化、儲存與傳遞圖片和影片，還能做即時音訊／視訊——不用自己搭建一套媒體處理流程。

自己處理媒體要顧轉碼、儲存、播放器和全球 CDN——非常費工。Cloudflare 的媒體產品把這些都包在一個簡單的 API 後面，讓你快速上線照片、影片和即時通話。
